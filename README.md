# create-zen

**Start a new project with one command.**

</div>

A small CLI that lets you choose and clone one of three ready-to-use Zen starters.

## Quick start

```bash
npm create zen@latest
```

Or with pnpm:

```bash
pnpm create zen@latest
```

Enter your project name and choose a starter:

| Starter | Description | Styling | Markup | Languages and interactivity |
| --- | --- | --- | --- | --- |
| [**Basis**](https://github.com/dmitry-conquer/zen-starter) | Foundational BEM-based markup for legacy and class-driven projects | SCSS and BEM | HTML and Handlebars | TypeScript |
| [**Express**](https://github.com/dmitry-conquer/zen-express) | Fast utility-first frontend implementation | Tailwind CSS v4 | HTML and Handlebars | TypeScript and Alpine.js |
| [**WordPress**](https://github.com/dmitry-conquer/zen-wordpress) | Direct frontend development inside a production-ready WordPress theme | Tailwind CSS v4 | PHP and WordPress templates | PHP, TypeScript, and Alpine.js |

The CLI clones the selected template into a new directory and removes its Git history, so you can start with a clean repository.

## Next steps

```bash
cd my-project
npm install
npm run dev
```
